Multivariate mixture model with antibody cross-reactivity

Fits all antigens at once with the multivariate Gaussian mixture of O’Driscoll et al. (2025), as written in multiSero_noStrata_improved_v2_antigenLoc_seroVec.stan. One Gaussian component per combination of infection status with the pathogens assumed present; antibodies raised by one pathogen also bind the others, by a cross-reactivity φ. It estimates prevalence, cross-reactivity and each person’s infection status together. With the page’s defaults it reproduces the main analysis of the paper. Everything runs in this browser tab, and files you load are never uploaded.

    How these priors are computed

    Each antigen gets a two-component Gaussian mixture fitted to its own log titres by EM, from 20 random starts. The lower component centres mu0 and sd0, the gap between the components centres mu1, and the upper component centres sd1. The plots below show the result over the data.

    Copies them to “One prior per antigen”, where you can change them.

    Priors shared by every antigen

    These have no antigen-specific location, so they are the same whichever option above is used. Each panel is the prior density itself: the curve is what the sampler is told to believe before it sees a single titre.

    Priors over the data

    Each panel shows the log titres of one antigen with the two components its prior locations imply: N(mu0, sd0) for the negatives and N(mu0 + mu1, sd1) for the positives. The positive one is drawn for every antigen, since any of them may turn out to be present. Curves are scaled to the tallest bar, so their heights carry no information, only their positions and widths. The bar along the axis is ±1 prior scale on the location, and the dashed line is the midpoint between the two components.

    3

    Present pathogens

    Which pathogens are assumed to have transmitted in this population. Titres against every other antigen are then explained by negative titres plus cross-reactivity from these. The number of Gaussian components is 2P, so each extra present pathogen doubles the work. Two ways to decide, and you can move between them at any time.

    Round 1 fits every antigen in turn as the only present pathogen and keeps the one with the highest log-likelihood. Each later round adds the antigen that improves the fit the most, until the likelihood increment percentage per component (LIPpc) falls below the threshold. Because adding a pathogen doubles the number of Gaussian components, LIPpc scales the gain by the components it costs.

    7

    Prevalence by covariates

    Lets prevalence differ between groups of samples, as in the location-specific and location-and-age-specific versions of the paper. Every cell gets its own prevalence for each present pathogen; the antibody distributions and the cross-reactivities are shared by all samples, so small cells borrow strength from the rest. Each model is a separate run of the sampler and takes about as long as the base model.

    Present pathogens to run this for

    Each set is fitted separately, so you can ask what the split by location looks like under the model you chose and under another one. The cells, the priors and the samples are the same for every set.
