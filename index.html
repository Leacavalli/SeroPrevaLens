SeroPrevaLens

Estimate SeroPrevalence using Bayesian Mixture Models

Fits a two-component Bayesian mixture model to each antigen, one at a time. You can check each fit and its posteriors, and estimate prevalence for each antigen, then run sensitivity analyses to test how much the estimates depend on the priors. It works directly on SerolyzeR output. Everything runs in this browser tab, and files you load are never uploaded.

      Sensitivity analysis

      Refit with other priors

      Each scenario changes one part of the baseline prior, or swaps in another prior method. All scenarios use the same data and random seeds, so differences come from the priors rather than Monte Carlo noise. The perturbation sizes set the grid; open the full grid to edit any cell or add your own scenarios. “Run for all antigens” builds the same grid around each antigen’s own baseline prior (only the antigens ticked in step 2); scenarios you untick stay unticked for every antigen, while edited cells and added rows apply only to the antigen shown.

      Perturbation sizes (normal priors)
      What each setting does

      A normal prior has a location (where it is centred, the value you expect) and a scale (its SD, how sure you are). A location change asks “what if my best guess were a little off?”; a scale change asks “what if I were more or less certain?”. Each setting adds a pair or a single scenario that changes one prior and keeps everything else at the baseline. All values are on the scale the model is fitted on (log of the antibody measurement, unless “Transform: none”).

      mu0 location ±
      Moves the centre of the prior on mu0, the mean of the seronegative group, down and up by this amount (two scenarios). Tests whether the estimate depends on exactly where you told the model negatives sit. On the log scale, 0.25 is about a 1.3-fold change in the antibody value.
      muR location ±
      Moves the centre of the prior on muR, the gap between the positive and negative means (mu1 = mu0 + muR), down and up by this amount (two scenarios). A smaller gap lets the positive group sit closer to the negatives, which often changes how many samples are counted positive.
      SD locations ± fraction
      Multiplies the centre of the priors on sd0 and sd1, the spreads of the negative and positive groups, by 1 − fraction and 1 + fraction (two scenarios each). 0.25 means 25% narrower and 25% wider groups. Tests whether assumptions about how tight each group is shift samples between them.
      Narrow scale ×
      Multiplies the scale of the priors on muR, sd0 and sd1 by this factor (below 1), one scenario each. A more confident prior pulls these parameters harder towards the baseline locations. If the estimate moves, the baseline prior was already doing a lot of work.
      Wide scale ×
      Multiplies the scale of the priors on mu0, muR, sd0 and sd1 by this factor (above 1), one scenario each, letting the data speak more. If prevalence barely moves, the data, not the prior, drive the estimate. It also sets the “all scales” joint scenario below.
      Near-free mu0 scale
      Replaces the scale of the mu0 prior with this value, so the negative mean is almost unconstrained. Added only when it is wider than the wide-scale scenario. The strongest test of whether the data alone can locate the negative group; if the fit fails or prevalence jumps, the prior on mu0 is essential.

      Always added, whatever the settings: other Beta priors on prevalence (uniform Beta(1, 1), Jeffreys Beta(0.5, 0.5), Beta(1, 5) as in Table 1 of O’Driscoll et al., and a strong low-prevalence Beta(1, 20)); two joint scenarios that widen every scale at once (×2, and × the wide factor with a uniform prevalence prior); and priors built by the other methods in step 2. Location changes that would cross a parameter’s limit are clipped to just inside it and labelled.

      Rule of thumb: location changes show whether a wrong guess matters; scale changes show whether how strongly you believed it matters. A robust estimate barely moves under either. Change a setting, then press “Rebuild grid”.

      The math

      The model is a single-dimension (1D) two-component Gaussian mixture, fitted to one antigen at a time, as in Mixture1D.stan. O'Driscoll et al. (2025) fit the same model, with the priors in their Table 1, as a comparison for their multivariate cross-reactivity model.

      1. Data

      For each sample i = 1, …, N, the page analyses yi = log xi, where xi is the antigen measurement (RFI in the example data). With "Transform: none" it uses xi as given.

      2. Mixture of two populations

      Each sample has an unobserved status zi (1 = seropositive, 0 = seronegative) with P(zi = 1) = π, the prevalence. Given the status, the log titre is normal:

      yi | zi = 0 ~ N(μ0, σ02),   yi | zi = 1 ~ N(μ1, σ12),   μ1 = μ0 + μR,   μR > 0

      Summing over the two possible statuses gives the density of one observation, where φ(·; m, s) is the normal density:

      p(yi | θ) = (1 − π) φ(yi; μ0, σ0) + π φ(yi; μ1, σ1),   θ = (π, μ0, μR, σ0, σ1)

      Writing the positive mean as μ0 + μR with μR > 0 keeps the positive component to the right of the negative one, so the two labels cannot swap.

      3. Likelihood

      log L(θ) = Σi=1N log [ (1 − π) φ(yi; μ0, σ0) + π φ(yi; μ1, σ1) ]computed with log-sum-exp for numerical stability

      4. Priors and posterior

      p(θ | y) ∝ L(θ) · p(θ),   restricted to the bounds of each parameter

      Every prior on this page has the form of Mixture1D.stan (Table 1 of the paper, priors entered by hand or uploaded, and the peak and tail rule). Each normal prior is truncated to its limits [L, U]:

      π ~ Beta(a, b),   μ0 ~ N(m0, s0),   μR ~ N(mR, sR),   σ0 ~ N(mσ0, sσ0),   σ1 ~ N(mσ1, sσ1)

      Table 1 values: π ~ Beta(1, 5); μ0 ~ N(0, 0.1) on [−1, ∞); μR ~ N(3, 0.1) on [0, ∞); σ0 ~ N(0.4, 0.05) and σ1 ~ N(0.7, 0.05) on [0, ∞). The peak and tail rule (the priors suggested by the data) puts m0 at the peak of a smoothed histogram, mσ0 at the root-mean-square distance of the values below that peak, and m0 + mR near the 95th percentile.

      5. What is reported

      • The prevalence estimate is the posterior median of π with a 95% credible interval (the 2.5% and 97.5% posterior quantiles).
      • Each sample's probability of being seropositive, averaged over posterior draws:
      P(zi = 1 | yi, θ) = π φ(yi; μ1, σ1)(1 − π) φ(yi; μ0, σ0) + π φ(yi; μ1, σ1)
      • The midpoint cutoff (μ0 + μ1) / 2 and the classification boundary, where that probability equals 0.5. The two coincide only when σ0 = σ1 and π = 0.5; at low prevalence the boundary sits to the right of the midpoint.
      • Separation: sep = μR / ((σ0 + σ1) / 2). Below about 1.5 the components overlap so much that the split is driven largely by the prior.

      6. Sampling

      Each parameter x with bounds [L, U] is mapped to an unconstrained value v the way Stan maps a bounded declaration, and the log density gains the log of the Jacobian |dx/dv|:

      both bounds: x = L + (U − L) · logit−1(v)   lower only: x = L + ev   upper only: x = U − ev   none: x = v

      The posterior is explored with the No-U-Turn sampler (multinomial NUTS with the generalised U-turn criterion), using Stan's warmup: the step size is tuned by dual averaging to an average acceptance of 0.8, and a dense mass matrix is estimated over windows of 75, then 25, 50, 100… iterations, then 50. Up to 1,000 draws per chain are kept.

      7. Sampler check

      Each chain is split in half, all draws are ranked together, and the ranks r of the S draws are normalised:

      z = Φ−1( (r − 3/8) / (S + 1/4) ),   R̂ = √( V̂ / W ),   V̂ = n − 1n W + Bn

      W is the mean within-chain variance and B / n the variance of the chain means. The page reports the larger of the bulk R̂ (on z) and the folded R̂ (on |y − median|), as in the posterior package (Vehtari et al. 2021). Bulk ESS is S / (1 + 2 Σt ρt), with autocorrelations ρt summed using Geyer's initial monotone sequence. Tail ESS is the smaller ESS of the indicators θ ≤ q0.05 and θ ≤ q0.95. The MCSE of the median is half the distance between the draws at quantiles 0.5 ± √(0.25 / ESS0.5). Chains are grouped when every parameter median is within 3 within-chain SDs of the others’; more than one group means the chains gave different results. When a group of chains describes almost the same mixture density as the others (total variation distance below 0.1) with prevalences adding up to about 1, it has swapped which component it calls positive. The check fails on that, on any divergent transition or on R̂ ≥ 1.05, and warns when R̂ ≥ 1.01 or either ESS < 400.

      8. Sensitivity measures

      Each scenario refits the model with one part of the baseline prior changed, using the same data and random seeds, and compares the estimates with the baseline:

      Δπ = median(π | scenario) − median(π | baseline),   Δ / SD = Δπ / SD(π | baseline)

      A scenario is flagged when it moves the prevalence by more than the meaningful change set on the page (in percentage points), or another parameter by more than one baseline SD. A Δπ smaller than one baseline SD is within the estimate's own uncertainty. When all antigens are run at once, each antigen gets the same perturbations applied to its own baseline prior, and the summary counts, for each antigen, the scenarios with |Δπ| above the threshold.

      9. Prevalence by covariates

      Step 5 gives each sample i the prevalence of its cell c(i), one combination of the chosen metadata values, and keeps everything else shared:

      yi ~ (1 − πc(i)) N(μ0, σ0) + πc(i) N(μ0 + μR, σ1),   πc ~ Beta(a, b) independently for each cell

      The base model has a single cell. All models for an antigen are fitted to the same samples (those with a value for every column used by any model), so their log-likelihoods can be compared. The mean log-likelihood is the posterior mean of Σi log p(yi | θ). ELPD-LOO = Σi log p(yi | y−i) is estimated by Pareto-smoothed importance sampling (Vehtari, Gelman & Gabry 2017), with a tail of min(0.2S, 3√S) draws and relative efficiency 1; its SE is √(N var(elpdi)), and the SE of a difference between two models uses the pointwise differences. p_loo = Σ log means p(yi | θs) − ELPD-LOO. The sum over antigens adds the ELPDs; its ΔELPD SE adds the variances of the per-antigen differences.

      10. Limits of the 1D model

      • Each antigen is fitted on its own, so antibodies raised by a related virus count as positives. O'Driscoll et al. show that 1D fits suggest WNV prevalence of 7.5% that their multivariate model attributes to cross-reactivity from JEV.
      • Prevalence split by a metadata column fits each group separately with the same prior (no pooling across groups).
      • Like the paper, the model assumes antibodies persist after infection; waning would make prevalence of past infection an underestimate.

      File format

      Data: SerolyzeR's per-plate or merged output, as written by process_plate() or merge_plate_outputs(). One row per sample, a sample_name column, then one column per antigen. A plate_name column, if present, is kept as metadata.

      sample_nameDENV1DENV2…CHIKV
      CHPI_11.070.67…3.68
      CHPI_214.031.00…30.87

      Metadata (optional): one row per sample, a column with the same sample names as the data file, then any columns you want to filter or split by. The sample column can have any name (sample_name, UID, ID…): the page uses the column whose values match the most sample names in the data.

      sample_nameupazilaageG
      CHPI_1Chapai Nawabganj Sadar5
      CHPI_2Chapai Nawabganj Sadar3

      Values can be MFI, RAU or nMFI; the page analyses their logarithm unless you choose otherwise. SerolyzeR keeps standard and blank wells in its output; they are dropped by the Exclude samples list under Advanced settings and, when metadata is loaded, because they have no metadata row.

      From the paper

      • The example dataset (split here into a SerolyzeR-style data file and a metadata file): anonymised antibody measurements from a cross-sectional serosurvey of 1,453 people in Chapai Nawabganj, Bangladesh, in 2014. Values are relative fluorescence intensities (median fluorescence ÷ the individual SNAP-tag background) against EDIII of DENV1–4, JEV, WNV, TBEV, YFV and ZIKV and E2 of CHIKV. The paper's whole-E DENV ELISA is left out of the example. Please cite the paper if you use these data.
      • The single-dimension (1D) two-component mixture, which the paper fits to each antigen separately as a comparison for its multivariate model.
      • The default priors and limits: Table 1 of the paper. With them, this page reproduces the paper's reported 1D estimates, e.g. DENV3 10.6% (95% CrI 8.9 to 12.4%) and WNV 7.5% (5.7 to 9.5%).
      • Data and code: doi:10.5281/zenodo.17340210 and github.com/meganodris/MultiSero.
